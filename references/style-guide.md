# 【风格名称】

**ZOOM IN! 认知拼贴海报**（Zoom-In Cognitive Collage Poster）
别名：复古剪贴簿人物海报 / Riso 拼贴肖像海报

# 【适用场景】

- 人物个性海报、社交头像卡片、生日/纪念/兴趣画像
- 「认知自我画像」类视觉：用拼贴元素表达一个人的兴趣、记忆与身份
- 输入：1 张用户自拍（正脸或 3/4 侧脸，露肩以上）+ 5 个元素关键词
- 输出：1:1 方形完整海报画面（生成描述可直接投喂 AI 绘图模型）

# 【核心视觉特征】

1. **画幅与外框**：1:1 正方形；最外层为对角线彩虹渐变描边框（左上暖橙黄 → 中段砖红 → 右下紫），框宽约占画面边长 3–4%；框内留一圈白色毛边/撕纸内衬，内衬宽约 2–3%。
2. **背景结构**：密集拼贴墙（剪贴簿页面感），由 4–9 个矩形拼贴块拼接而成，块与块之间有细白缝（2–6px）。拼贴块类型混搭：复古印刷海报、黑白漫画分格、老式插图、照片、纯色纹理块。
3. **主体呈现**：人物从自拍照片硬边抠图，叠放在拼贴墙**前方**，位置底部居中偏左，胸像景别；身后拖 2–3 层错位色边阴影（墨绿 / 紫 / 青，向右下偏移 8–20px），形成丝网印刷套色错位感。
4. **质感**：整图覆盖细颗粒噪点 + 半调网点 + 纸张纤维纹理；riso / 丝网印刷质感，色层轻微错位，禁止数码平滑渐变。
5. **光线**：平面光（flat lighting），无方向性投影、无摄影棚布光；人物面部保留原照片光影不做重打光。
6. **固定锚点元素**（每张海报必备）：
   - 右上角："ZOOM IN!" 立体贴纸字标志（白字紫影 + 黄色箭头）
   - 右下角：向日葵贴纸
   - 左上角：小照片——一只手拿红花与复古胶片相机
7. **两种色彩模式**（二选一，按元素气质定）：
   - 模式 A 全彩复古：背景为彩色老海报与彩色插图
   - 模式 B 黑白漫画：背景纯黑白漫画分格，彩色仅出现在人物、错位色边与贴纸

# 【配色规范】

| 用途 | 色值 |
|---|---|
| 外框渐变（对角线） | #F7B733 → #E8593C → #8E5BD9 |
| 纸白内衬 / 拼贴缝 | #F2EDE3 |
| 芥末黄（主色） | #D9A441 |
| 砖红（主色） | #B5442E |
| 青蓝（主色） | #2E7F86 |
| 米奶油（底色块） | #EFE6D0 |
| 墨黑（漫画/描线） | #1A1A1A |
| 点缀：向日葵黄 | #F2B705 |
| 点缀：朱红 | #D23B2E |
| 错位阴影层 | 墨绿 #4A5D3A / 紫 #7C5CB0 / 青 #3E8E8A |

**色彩占比（模式 A）**：芥末黄 ~20%、米奶油 ~15%、砖红 ~15%、青蓝 ~12%、墨黑 ~10%、其余为纸白与点缀色。
**色彩占比（模式 B）**：背景黑白（#111/#FFF + 网点灰）占 60–65%；彩色仅占 15–20%（人物 + 色边 + 贴纸）。
**面积分配（所有模式通用）**：背景拼贴 55–60% / 人物 20–25% / 外框+内衬 12–15% / 点缀贴纸 ≤5%。

# 【构图与景别】

- **画幅**：1:1。
- **人物景别**：中近景胸像（头顶可裁发梢，底边裁至胸口）；头顶留白 8–12%。
- **人物位置**：水平中心在画面 40–45%（偏左）；垂直贴底，头顶约在画面 45–55% 高度处。
- **背景布局**：「上重下留」——最大叙事拼贴块放人物头后右上方（画面右上 1/4 最醒目位），人物躯干自然遮住下方拼贴块下半部。
- **前景层次**：允许 1 个小元素压在人物肩部/头发边缘，遮挡面积 <10%，制造前后纵深。
- **贴纸分布**：散布四角，一律避开人物面部区域。
- **人像姿态细则**：正面或 3/4 朝向镜头，自然直立或微侧，肩膀放松；表情为露齿笑或平静中性，禁止夸张表情；可比耶/托脸等单手小动作。

# 【人像身份规则】

1. **面部 100% 保留**：五官、脸型、肤色、发型发色、痣、眼镜等个人特征一律不得修改、美化、瘦脸或风格化为插画；以参考图（image reference / img2img，人物强度 ≥0.85）锁定身份。
2. **服装**：保留自拍原图服装；如需融合仅加轻微纸纹/描边处理，不换装。
3. **融合方式**：硬边抠图叠放，人物轮廓带 1–2px 白色描边或撕纸毛边；身后叠 2–3 层错位色边阴影；人物全身叠加与背景一致的噪点颗粒，使其像被「印刷」进海报。
4. **互动规则**：第 4 元素可与人物互动（手持/佩戴/印在服装上），但任何元素不得遮挡五官。
5. **禁止**全身像、背对镜头、多人。

# 【负面约束】

生成时必须避免（negative prompt）：

- 3D 渲染感、CG 光滑质感、数码平滑渐变、强方向性摄影布光、景深虚化
- 改变人物身份特征（换脸、美颜、改发型发色、插画化面部）
- 任何拼贴块/文字/贴纸遮挡人物五官
- 真实可读的长段文字（拼贴内文字为装饰性伪文、乱码印刷字）
- 水印、签名、边角 logo（固定 "ZOOM IN!" 标志除外）
- 高饱和荧光色、霓虹色
- 全身像、背对镜头、多人同框、手部畸形
